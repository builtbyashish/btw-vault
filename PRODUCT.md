# Product

## Platform

adaptive

## Stack

React Native, Expo SDK 57, Expo Router, TypeScript, React Native StyleSheet

## Users

Individuals seeking a 100% offline, local-only, zero-knowledge encrypted password manager and vault to safely store sensitive credentials without cloud tracking or server vulnerabilities.

## Product Purpose

Provide a military-grade, privacy-first offline encrypted vault on mobile devices to store, generate, filter, and manage passwords, credit cards, secure notes, and identities using AES-256-GCM and Argon2id.

## Positioning

100% local, zero-network, local-only storage with native biometric authentication and zero-knowledge architecture. No servers, no accounts, no tracking.

## Operating Context

Daily quick retrieval of passwords, credit cards, and PINs; password generation; encrypted backup exports; auto-lock on app backgrounding or inactivity.

## Capabilities and Constraints

- AES-256-GCM encryption with Argon2id 256-bit derived master keys.
- Native Biometric authentication (Face ID / Touch ID / Fingerprint) stored in Keychain/KeyStore via Expo SecureStore.
- Instant search and category filter (Logins, Cards, Notes, Identities).
- Custom field support (Text, Hidden/Masked, URL, Email).
- Auto-clearing clipboard (30s timeout).
- Offline Encrypted JSON backup export & import.
- Pure dark theme UI designed for mobile devices.

## Brand Commitments

- Name: btw vault
- Tone: High-security, ultra-clean, modern, precise, trustworthy, pure white minimalist aesthetics with signature text wordmark.

## Product Principles

1. **Absolute Privacy & Zero Knowledge**: No telemetry, no remote servers, no cloud sync. All encryption happens locally.
2. **Instant & Effortless Retrieval**: High contrast, scanable typography, fast search, one-tap field copying.
3. **Defense in Depth**: Master password + biometric quick unlock + inactivity auto-lock + auto-clearing clipboard.
4. **Tactile & Refined Simplicity**: Clean visual feedback, tactile dark mode card layers, vibrant security indicators.
