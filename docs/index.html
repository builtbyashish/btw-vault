Privacy, Data Safety & App Access

btw vault is engineered with an absolute commitment to privacy. We cannot see, sell, or track your data.

🛡️ Privacy Policy

Effective Date: October 15, 2026 | Developer: Ashish Ranjan

btw vault is an offline-first, client-side encrypted password manager. The application operates under a strict zero-knowledge architecture.

1. Zero Data Collection

We do not collect, transmit, store, or sell any personal information or telemetry. There are no advertising SDKs, no behavioral tracking cookies, and no remote servers owned or operated by us that store your vault data.

2. Local Cryptographic Storage

All items, passwords, credit card numbers, notes, and custom categories are stored locally in an encrypted database using SQLCipher (AES-256 in CBC mode). Your Master Password is protected using the memory-hard Argon2id key derivation function with a 256-bit cryptographic salt.

3. Biometric Unlock

Biometric authentication (Fingerprint / Face ID) is handled strictly by your device's native hardware security module (Android Keystore / Secure Enclave). The app never has access to raw biometric data.

4. Optional Google Drive Cloud Backup

If you choose to link Google Drive for backups:

  • Vault data is encrypted on your device before upload. Google only receives an encrypted ciphertext container.
  • Access is limited to the hidden App Data folder (drive.appdata) created by the app.
  • The developer has no server or gateway through which this data passes.

5. Complete Data Deletion (Wipe Vault)

You can permanently erase all vault data, cryptographic keys, and application preferences at any time by tapping "Wipe Vault" in the app settings.

🔑 App Access & Review Instructions

Instructions for the Google Play review team and security auditors:

All functionality in btw vault is accessible without special accounts, paywalls, or corporate subscriptions.

1. LAUNCH & SETUP:
   - On first launch, create any master password (min 8 chars, e.g. "ReviewerPass123!").
   - Biometric unlock can be toggled or skipped.

2. CREATE & INSPECT VAULT ITEMS:
   - Tap "+" to create Login credentials, Payment Cards, Notes, or Custom Categories.
   - Test password generator and clipboard copying.

3. SECURITY & WIPING:
   - Open Settings to test Auto-Lock, Anti-Capture screen protection, and Export Backup.
   - Tap "Wipe Vault" under Danger Zone to verify complete local deletion.
