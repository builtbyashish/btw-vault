# Security Policy

**btw vault** is designed as a Zero-Knowledge, offline-first personal cryptographic vault. Security and user privacy are our highest priorities.

---

## 🔐 Supported Versions

Security updates and patches are actively applied to the latest release on the `main` branch:

| Version | Supported |
| :--- | :---: |
| 1.3.x | ✅ Yes |
| < 1.3.0 | ❌ No |

---

## 🛡️ Reporting a Vulnerability

If you believe you have discovered a security vulnerability in **btw vault** (e.g. key derivation weaknesses, SQLCipher leaks, memory hygiene issues, or authorization bypasses):

1. **Do NOT open a public GitHub issue.** Public issues disclose vulnerabilities before a patch can be developed and released.
2. Please report the issue privately using one of the following methods:
   - **GitHub Security Advisory**: Open a private draft security advisory via [GitHub Security Advisories](https://github.com/builtbyashish/btw-vault/security/advisories/new).
   - **Email**: Send detailed vulnerability reports directly to **ashishranjan.ar7@gmail.com** with the subject line `[SECURITY] btw vault vulnerability report`.

### What to Include in Your Report

To help us triage and resolve the issue quickly, please provide:
- A clear description of the vulnerability and its potential impact.
- Step-by-step instructions or Proof of Concept (PoC) code to reproduce the issue.
- App version, operating system, and hardware architecture tested on.
- Any suggested fixes or mitigations.

---

## ⏱️ Response Timeline

- **Acknowledgment**: We will acknowledge receipt of your vulnerability report within **48 hours**.
- **Assessment**: We will investigate and provide a severity rating within **5 business days**.
- **Fix & Disclosure**: We will collaborate with you to develop a patch and coordinate a public release timeline.

---

## 🤝 Safe Harbor

If you conduct vulnerability research in good faith, in adherence with this policy, and without attempting to access or compromise other users' data, we consider your actions authorized and will not initiate legal action against you.
